# TabKnight Landing Page

The standalone website for [TabKnight](https://github.com/AitorGallardo/tabknight), an open-source Chrome command surface for tabs, bookmarks, history, URLs, and web search.

This project contains the CurrentV3 editorial-grid design and follows the visitor's operating-system light or dark appearance automatically.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

The project is a standard Next.js application intended for independent deployment on Vercel.
