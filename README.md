# TabKnight Landing Page

The standalone website for [TabKnight](https://github.com/AitorGallardo/tabknight), an open-source Chrome command surface for tabs, bookmarks, history, URLs, and web search.

This project contains the CurrentV3 editorial-grid design and follows the visitor's operating-system light or dark appearance automatically.

## Links

- [Live landing page](https://tabknight-landingpage.vercel.app/)
- [TabKnight extension source](https://github.com/AitorGallardo/tabknight)
- [Privacy policy](https://github.com/AitorGallardo/tabknight/blob/main/PRIVACY.md)

## Design

CurrentV3 uses a restrained editorial grid, TabKnight's red accent, product-first demonstrations, and a minimal animated privacy diagram. The repository preserves the original landing-page evolution in its Git history, including the CurrentV3 winner snapshot and subsequent typography, media, illustration, motion, and system-theme refinements.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

The project is a standard Next.js application intended for independent deployment on Vercel.
